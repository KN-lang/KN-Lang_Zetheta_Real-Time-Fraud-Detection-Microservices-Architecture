# Day 09 - Graph Database Schema

Neo4j stores `Customer`, `Account`, `CardToken`, `Device`, `IPAddress`, `Merchant`, `Beneficiary`, and `Transaction` nodes. Relationships include `OWNS`, `USES`, `INITIATED`, `PAID`, `LOGGED_IN_FROM`, `TRANSFERRED_TO`, and `SHARES_SIGNAL_WITH`. Constraints enforce unique IDs for all entity nodes.
